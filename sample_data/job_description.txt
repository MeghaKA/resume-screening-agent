Job Title: Junior Machine Learning Engineer

We are looking for a Junior Machine Learning Engineer to join our analytics team.

Responsibilities:
- Build and evaluate machine learning models (regression, classification, ensemble methods)
- Perform data cleaning, feature engineering, and exploratory data analysis
- Work with Python, Pandas, and Scikit-learn on real-world datasets
- Communicate findings clearly using visualization tools such as Power BI or Tableau
- Collaborate with the team using Git/GitHub

Required Skills:
- Strong Python programming skills
- Experience with Pandas, NumPy, Scikit-learn
- Understanding of machine learning fundamentals (regression, classification, model evaluation)
- Familiarity with SQL
- Good communication skills

Nice to Have:
- Experience with explainable AI (SHAP, LIME)
- Exposure to time-series analysis
- Experience with cloud platforms (AWS)
- A degree in Computer Science, Data Science, or a related field
